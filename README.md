# Agent Approval Desk

A static, no-account canvas for reviewing everything your AI agents are waiting on you for.

What is included:
- A radar-style "Agent Control Tower" dashboard
- Pull requests from Copilot, Dependabot, and custom bots
- Draft approvals from a local `approvals.json` file
- Click-to-review details, risk notes, and quick approval workflows
- Focus mode for clearing the lowest-fuel items first
- Sample data so it works immediately without any connected account

Open `index.html` in a browser to use it.

This repo intentionally does not auto-send or auto-merge anything.
